Contexte du Projet – Agence MaBagnole

L’agence MaBagnole souhaite moderniser son système de location de véhicules afin de le rendre plus modulable, performant et maintenable. L’objectif principal est de refondre le module de gestion des locations en adoptant une architecture MVC (Modèle–Vue–Contrôleur), permettant ainsi une meilleure séparation des responsabilités, une maintenance simplifiée et une préparation pour de futures évolutions fonctionnelles.

La solution proposée doit être développée en PHP orienté objet, interagir avec une base de données MySQL, et respecter les bonnes pratiques de conception logicielle, incluant l’utilisation de design patterns tels que Singleton et, en bonus, le Repository Pattern.

Objectifs du projet

Le projet vise à concevoir un module complet de gestion des locations de véhicules, répondant aux besoins des clients et des administrateurs, avec les fonctionnalités principales suivantes :

Pour les clients :

Inscription et authentification sur la plateforme pour accéder aux services.

Parcourir les catégories de véhicules disponibles à la location.

Consulter les détails d’un véhicule, incluant modèle, prix, disponibilité et description.

Rechercher un véhicule par modèle ou par caractéristiques spécifiques.

Filtrer dynamiquement les véhicules selon leur catégorie.

Pagination des résultats pour faciliter la navigation :

Pagination manuelle en PHP.

Pagination interactive avec DataTables.

Réserver un véhicule en précisant les dates et lieux de prise en charge.

Laisser un avis ou une évaluation sur un véhicule loué.

Modifier ou supprimer ses propres avis, avec gestion en Soft Delete.

Pour les administrateurs :

Ajouter, modifier ou supprimer des véhicules, catégories et réservations.

Insertion multiple pour ajouter plusieurs véhicules ou catégories en masse.

Accéder à un dashboard présentant les statistiques clés :

Nombre de réservations.

Avis des clients.

Véhicules disponibles.

Compétences visées

Ce projet permettra de développer et consolider les compétences suivantes :

Conception d’une application web respectant l’architecture MVC.

Implémentation de classes métiers et gestion des données via DAO, avec possibilité d’appliquer le Repository Pattern.

Interaction avec une base de données MySQL en POO avec PDO.

Application des design patterns tels que Singleton pour la gestion des connexions à la base de données.

Manipulation des vues avec une logique contrôlée côté serveur.

Gestion du routage et de l’affichage dynamique des pages.

Documentation et organisation du code selon les bonnes pratiques de développement.

Résumé

En résumé, ce projet vise à refondre et moderniser le module de gestion des locations de l’agence MaBagnole en proposant une solution robuste, évolutive et maintenable, tout en garantissant une expérience utilisateur optimale pour les clients et une administration simplifiée pour les gestionnaires du système.
